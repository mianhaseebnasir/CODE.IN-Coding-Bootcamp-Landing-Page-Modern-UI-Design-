# 🚀 CODE.IN – Coding Bootcamp Landing Page

A modern and visually appealing landing page designed for an online coding bootcamp platform. This project focuses on clean UI design, structured layout, and branding presentation.

---

## 📌 Overview

CODE.IN is a front-end web project that represents a coding education platform. It highlights different offerings such as bootcamps, live coding sessions, and application systems in a structured and user-friendly interface.

---

## 🎯 Features

- ✅ Clean and modern UI design
- ✅ Structured layout using HTML & CSS
- ✅ Branding-focused landing section
- ✅ Feature showcase with visual blocks
- ✅ Footer with social media integration
- ✅ Lightweight and fast loading

---

## 🧩 Sections Included

- 🔹 Navigation Bar (About, Products)
- 🔹 Hero Section (Logo + Tagline)
- 🔹 Feature Grid (Bootcamp offerings & services)
- 🔹 Application Section
- 🔹 Footer (Links + Social Icons + Credits)

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Remix Icons (for social media icons)
